## Sobre o projeto

Esse repositório é o código do meu site de portfólio: uma página única com seções de skills, projetos, experiência, formação e contato.

Construí com Next.js, TypeScript e Tailwind CSS, e usei o Claude Code como par de desenvolvimento — pela praticidade, pra automatizar parte do trabalho repetitivo, sem depender 100% dele.

O conteúdo (textos, projetos, experiência) fica centralizado em [`src/data/content.ts`](src/data/content.ts), separado dos componentes visuais em [`src/components/`](src/components/).

### Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- React Icons

## Como rodar localmente
